# 波形峰值与静音检测（从 0 实现）

起始环境只有这份说明、`samples/**` 与 `.gitignore`，没有实现代码，程序与页面都要新写。Python 3.13、只用标准库，不加依赖与构建步骤，自测用 `unittest` 且只读 `samples/**`。

## 一、范围

在仓库根写单文件程序 `wavepick.py`（库与命令行入口合一）：

    python3 wavepick.py analyze --input <文件或目录>… --out <报告.json>

库接口 `analyze(路径) -> dict`、`analyze_many(路径序列) -> dict` 与命令行共用同一套口径；报告默认写到 `var/report.json`（该目录不入库）。

`web/index.html`（配原生 ES module）是复核页：把波形画出来，事件区间标红、静音区间标灰，人工标注用虚线叠在上面便于比对，顶部给漏检数与误报数。页面上的区间与统计只能来自引擎输出，页面自己不重算检测。

明确不做的事：

- 不做降噪、增益调整、重采样、去混响、语音识别与说话人分离；不写出、不修改任何音频；
- 不支持多声道、非 16 位、非 PCM 的 WAV，也不支持压缩格式；目录输入不递归；
- 不做实时采集；页面不引外部资源（CDN、字体、图片、网络请求），不写构建脚本。

## 二、口径与公式

采样与帧：帧长固定 10 ms。设采样率 R、总采样数 S，第 n 帧（n 从 0 起）覆盖采样下标 `[⌊n·R/100⌋, min(⌊(n+1)·R/100⌋, S))`，帧数 `N = ⌈100·S/R⌉`，末帧允许短于 10 ms；帧下标 n 对应时间 n×10 ms。

幅度：采样 x 为 int16，归一化 `a = x/32768`（x = −32768 记 a = −1）。帧峰值 `P[n] = max|a|`，帧均方根 `E[n] = sqrt(mean(a²))`。

峰值事件（窗口、阈值、绝对门限）：

- 绝对门限 `A = 0.20`（满量程）；
- 相对阈值 `4×B[n]`：基线 `B[n]` 取当前帧**之前** 100 帧（1 s）内 P 的下四分位，即升序第 `⌊(m−1)/4⌋` 个（m 为窗口内实际帧数；m = 0 时 B = 0）。底噪高的录音会把门限顶上去，一条固定门限过不了；
- 起始条件 `P[n] ≥ max(A, 4·B[n])`；延续条件 `P[n] ≥ A/2 = 0.10`。

静音：静音帧当且仅当 `E[n] ≤ 0.004`。

抖动抑制与最短时长：

- 事件：间隔不超过 10 帧（100 ms）的候选段合并（等价说法：连续 11 帧不满足延续条件才结束）；合并后不足 3 帧（30 ms）的事件丢弃；
- 静音：段内连续非静音帧不超过 5 帧（50 ms）时不切断；合并后不足 50 帧（500 ms）的静音段丢弃。

区间：半开区间 `[start_ms, end_ms)`，端点是整数毫秒；每段另带强度 `peak` = 区间内采样绝对值的最大值（整数 0…32768，x = −32768 时取 32768）。

## 三、状态机与数据结构

事件状态机逐帧推进：IDLE 遇到起始条件就记起始帧进入 IN_EVENT；IN_EVENT 里每满足一次延续条件就更新活跃帧，连续 11 帧不满足就结束，区间为 `[起始帧, 活跃帧+1)`，回到 IDLE；文件结束时仍在 IN_EVENT 的同理收尾；收尾后按最短时长过滤。

静音扫描：静音帧连成候选段，连续 6 帧非静音才结束本段（≤5 帧毛刺并入），文件结束收尾后按最短时长过滤。

报告结构（每个输入文件一条）：

```json
{"version": 1,
 "files": [{"file": "noisy_floor.wav", "sample_rate": 16000, "channels": 1,
            "bits_per_sample": 16, "samples": 128000, "duration_ms": 8000,
            "events": [{"start_ms": 2000, "end_ms": 2060, "peak": 30071}],
            "silences": []}]}
```

## 四、输入输出与文件格式

- 输入 `samples/audio/*.wav`：RIFF/WAVE，`fmt` 为 PCM（format 1）、单声道、16 位；头部可能夹 `LIST`/`INFO` 这类额外块，要按块定位 `fmt` 与 `data`；`data` 长度与声明不符算损坏。
- 命令行：`python3 wavepick.py analyze --input <路径>… --out <报告 JSON>`；`--input` 可给文件或目录（只取其中的 `*.wav`，不递归），同一路径只算一次。参数不对、文件打不开、格式不支持时，向 stderr 打一行 `error: <文件名>: <原因>`，该文件不进报告，退出码 2；成功退出码 0。
- 报告 JSON：UTF-8、缩进 2 空格、键序与上例一致；`files` 按 `file` 字段的 Unicode 码点升序；`duration_ms = ⌈1000·S/R⌉`；`events`、`silences` 各自按 `start_ms` 升序、同值按 `end_ms` 升序；数字一律十进制整数。
- 标注 `samples/labels/<音频同名>.json`：只含 `file`、`events`、`silences` 三个键，区间字段与报告一致，是人工听审的对照基准。
- 页面：用 `python3 -m http.server 8000` 从仓库根打开 `http://127.0.0.1:8000/web/`；顶部是报告路径输入框（默认 `../var/report.json`）与加载按钮，`id="verdict"` 写合计的「漏检 m 个」「误报 n 个」；每个文件一块 `<svg class="scope" data-file>`，横轴 0…duration_ms 线性映到 0…1000，内含波形 `<path class="wave">`（WAV 采样的峰谷包络）、事件 `<rect class="event">`（红 `#d64545`）、静音 `<rect class="silence">`（灰 `#9e9e9e`）、标注 `<rect class="mark-event">` 与 `<rect class="mark-silence">`（无填充、虚线描边）；矩形带 `data-start-ms`、`data-end-ms`，x 与宽按毫秒线性取整。

## 五、性能与验收口径

预算（Python 3.13、单线程、冷启动计入）：2 小时 16 kHz 单声道（约 220 MB）一遍扫完不超过 180 s、峰值常驻内存不超过 128 MiB，且内存不随时长增长；样例单个不超过 1 s。

判定：

1. 漏检与误报：报告与 `samples/labels/**` 逐文件比对，重叠长度 ≥ 两者较短时长的 50% 记为配对；未配对的标注区间是漏检，未配对的输出区间是误报。漏检必须为 0，误报合计不超过 1 个；
2. 逐条核对：`samples/labels/<名>.json` 给出每个样例的完整期望，事件与静音条数、起止毫秒、强度都要对得上；
3. 确定性：同一份采样连跑两遍（可换 `PYTHONHASHSEED`），事件区间、静音区间与强度逐字节相同；
4. 页面：区间与统计来自报告与标注；事件红、静音灰、标注虚线；`verdict` 的 m、n 与第 1 条一致；无外部引用、控制台无报错；
5. 不许写死：不得读 `samples/labels/**` 参与计算，不得按文件名、时长或样例数特判；验收会换采样。

## 六、样例说明

五段采样都是 16 kHz、16 位、单声道 PCM，每段在 `samples/labels/` 下有同名标注：

| 文件 | 场景 | 时长（毫秒） | 事件数 | 静音段数 |
| --- | --- | --- | --- | --- |
| `soft_passage.wav` | 轻声段落 | 10000 | 0 | 0 |
| `noisy_floor.wav` | 底噪较高 | 8000 | 2 | 0 |
| `dense_transients.wav` | 密集瞬态 | 6000 | 10 | 0 |
| `long_silence.wav` | 长时间静音 | 16000 | 1 | 2 |
| `sudden_pop.wav` | 突然的爆音 | 12000 | 1 | 0 |

- `soft_passage.wav`：全程低电平内容（帧峰值不到 0.09）加底噪（帧均方根约 0.008），不该报出任何区间；头部夹一个 `LIST`/`INFO` 块，用来确认按块解析；
- `noisy_floor.wav`：底噪帧峰值约 0.08，相对阈值被顶到约 0.317；两次敲击各 60 ms（peak 30071、30470）；另有一段前 3 帧越过 0.20 的轻敲，低于相对阈值，不该报出；
- `dense_transients.wav`：每 600 ms 一次、每次 50 ms 的瞬态（peak 约 3 万）；另有一个 20 ms 孤立尖峰，短于最短事件时长，应丢弃；
- `long_silence.wav`：静音 [1500,11000) 与 [11060,16000)，中间夹 60 ms 敲击；第一段里的 20 ms 小脉冲（peak 1644）按抖动规则并入；另有 300 ms 低电平缺口短于 500 ms，不该报出；
- `sudden_pop.wav`：相隔 30 ms 的两次爆音按合并规则连成 [6000,6120) 一段，peak 32768。
